# CNC Calc Pro ⚙️

> Современная веб-платформа для мониторинга станков с ЧПУ, управления цеховыми задачами и оперативного расчета режимов резания.

**CNC Calc Pro** — это профессиональный инструмент для операторов станков с ЧПУ, технологов и начальников цехов. Приложение объединяет в себе цеховой дашборд в реальном времени, канбан-оркестратор задач и инженерный калькулятор с генератором G-кода.

---

## 🚀 Основные модули

### 1. Мониторинг Цеха (Dashboard)
- **Живые карточки оборудования**: Отображение статусов станков (`В работе`, `Ожидание`, `Ошибка`) и выполняемых ими задач.
- **Интерактивные таймеры**: Динамический обратный отсчет времени до завершения обработки детали.
- **График OEE**: Визуализация общей эффективности работы оборудования в течение смены (на базе Recharts).

### 2. Оркестратор Задач (Projects)
- Управление бэклогом производства и очередью заданий.
- Распределение приоритетов (высокий, средний, низкий) и привязка к конкретному оборудованию.
- Канбан-структура для контроля стадий выполнения заказов.

### 3. Инженерный Калькулятор и Генерирование УП (Calculator & G-Code)
- **Расчет режимов резания**: Мгновенный перерасчет оборотов шпинделя ($S$) и подачи ($F$) на основе диаметра инструмента, скорости резания ($Vc$) и подачи на зуб ($Fz$).
- **2D Визуализация**: Наглядная симуляция траектории движения фрезы по обрабатываемому контуру.
- **Постпроцессор (G-Code)**: Автоматическая генерация управляющей программы под заданные параметры с возможностью сохранения.

## 🛠️ Технологический стек

- **Фреймворк**: React (Single Page Application)
- **Стилизация**: Tailwind CSS (индустриальная темная тема, оптимизированная для работы на производстве)
- **Графики**: Recharts
- **Иконки**: Lucide React

## 📦 Быстрый старт

Для запуска проекта локально выполните следующие шаги:

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/your-username/cnc-plus-pro.git
   cd cnc-plus-pro
   ```

2. **Установите зависимости**:
   ```bash
   npm install
   ```

3. **Запустите проект в режиме разработки**:
   ```bash
   npm run dev
   ```

4. Откройте браузер по адресу `http://localhost:5173`.
